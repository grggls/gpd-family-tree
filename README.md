# Damiani family tree

A read-only copy of the Gregory and Victoria Damiani family tree from Ancestry (tree 203378709), with the people, facts, records and photos from that tree.

- Start at the [index](index.html) for everyone in the tree.
- Each person has a page with dated facts, their family links, records and photos.
- Each record page has the transcription of an attached record.

Privacy: Social Security numbers are removed. Birth, census, marriage, death, burial and obituary records are left out when every person attached to them is still living. Living people are listed.
